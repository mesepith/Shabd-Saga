# Asset Pipeline

## Philosophy
All game art is generated **procedurally using code** (Canvas 2D + SVG). No external artists, no AI image generators needed. This gives us:
- Infinite resolution (vector → raster at any size)
- Consistent art style across all assets
- Build-time generation (no runtime cost)
- Easy iteration (change code → regenerate all)

## Pipeline Stages

```
SVG / Canvas drawing code
    │
    ▼
Build script (Node.js + canvas/sharp)
    │
    ▼
PNG sprite sheets / individual textures
    │
    ▼
Saved to public/assets/          ← Served by Vite
    │
    ▼
Loaded by Phaser PreloadScene    ← Consumed at runtime
```

## Asset Categories

### 1. Backgrounds (Parallax Layers)
- Generated per world (5-7 layers each)
- Layer order (back to front):
  1. Sky gradient (Canvas gradient fill + noise clouds)
  2. Far mountains (SVG paths converted to silhouettes)
  3. Mid-ground trees (SVG patterns with random variation)
  4. Near foliage (darker, larger elements for depth)
  5. Ground terrain (grassy hills with layered textures)
  6. Foreground elements (overhanging branches, foreground rocks)
- **Script**: `scripts/generate-backgrounds.ts`
- **Output**: `public/assets/backgrounds/world-{n}/layer-{n}.png`

### 2. Character Sprites
- Each character = composition of SVG shapes (body, head, limbs, tail)
- Animation frames generated by interpolating SVG transforms
- Character definitions:

| Character | Description | Palette |
|-----------|-------------|---------|
| Reetu (Fox Hero) | Orange fox with white chest, green scarf | Orange, white, green |
| Shadow Creeper | Dark purple blob with glowing yellow eyes | Purple, yellow |
| Letter Guard | Tall shadow figure, blue aura | Black, blue glow |
| Wise Owl (NPC) | Brown owl with spectacles | Brown, white, gold |
| Monkey Friend (NPC) | Small grey monkey, red bandana | Grey, red |
| Deer Mother (NPC) | Elegant deer with jewelry | Tan, gold |
| Jungle Boss | Giant shadow creature with vine tendrils | Dark green, black |
| Village Boss | Shadow demon with cookware (comical) | Dark, metallic |
| Palace Boss | Royal shadow guardian with scepter | Purple, gold |

- **Script**: `scripts/generate-sprites.ts`
- **Output**: `public/assets/sprites/{character}/{animation}.png`

### 3. Tilesets (Platforms)
- Generated tile textures with edge auto-tiling
- Terrain types: grass, stone, wood, palace marble
- Each tile: 32×32px or 64×64px
- Edge variations: top, bottom, left, right, corners
- **Script**: `scripts/generate-tilesets.ts`
- **Output**: `public/assets/tilesets/{type}.png`

### 4. UI Elements
- Buttons, panels, frames — SVG-based with cultural motifs
- WordBar tiles — rounded rectangles with color coding
- Star icons — gold stars with glow
- Heart icons — red hearts with pulse animation frames
- **Script**: `scripts/generate-ui.ts`
- **Output**: `public/assets/ui/{element}.png`

### 5. Letter Sprites (Akshar)
- Each letter rendered on a floating orb/pedestal
- Warm glow particle effect
- Color coded by type (consonant/vowel/matra)
- **Generated at build time** from language JSON `splitLetters`
- **Script**: `scripts/generate-letters.ts`
- **Output**: `public/assets/sprites/letters/{char}.png`

### 6. Particles & Effects
- Sparkle burst (letter collection)
- Shadow tendrils (enemy trail)
- Magic swirl (door opening)
- Confetti burst (boss defeated)
- Uses Phaser's built-in particle system with generated textures

## Dependency
- Build scripts require `canvas` (node-canvas) or `sharp` for PNG output
- Or: run in-browser, export canvas.toBlob() → download
- **Recommended**: `sharp` for simplicity (no native build dependencies)

## Running the Pipeline

```bash
# Generate ALL assets
npm run generate-assets

# Generate specific category
npm run generate-assets -- --category=backgrounds
npm run generate-assets -- --category=sprites
npm run generate-assets -- --category=letters --language=hindi
```

Assets are checked into git so they don't need regeneration on every install.
