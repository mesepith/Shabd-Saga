# Shabd Saga — Project Overview

## Purpose
A high-end hand-painted 2D platformer HTML5 game that teaches languages to children aged 6-12. The game fuses language learning seamlessly into core gameplay mechanics — kids learn by playing, not by studying.

## Target Audience
- **Primary**: NRI (Non-Resident Indian) kids aged 6-12 living in USA
- **Initial Language**: Hindi (Devanagari script)
- **Platform**: Web browser (desktop + tablets/iPads with touch controls)

## Core Philosophy
> Language learning is the gameplay, not a checkpoint.

Collecting letters, spelling words, and constructing sentences are the actions that unlock doors, defeat enemies, and progress through levels. Kids don't think "I'm studying Hindi" — they think "I need to spell this word to beat the boss."

## Game Concept
A young fox hero (default name: **रीतू / Reetu**) explores magical Indian-themed worlds:
1. **World 1: जंगल (The Jungle)** — A lush forest teaching animal and nature words
2. **World 2: गाँव (The Village)** — A rural Indian village teaching family and food words
3. **World 3: महल (The Palace)** — A royal palace teaching colors and body parts

## Key Features
- Hand-painted 2D parallax visuals (procedurally generated SVG/Canvas art)
- Platformer physics (run, jump, climb)
- Letter collection mechanics (floating Devanagari letters in the world)
- Word-building puzzles (drag-and-drop letter arrangement at locked doors)
- NPC dialogue system teaching vocabulary in context
- Shadow enemies that steal collected letters
- Boss fights requiring sentence construction
- Pronunciation via macOS TTS (Lekha/Kiyara voices for Hindi)
- Multi-language architecture — swap JSON to add any language
- Touch-first controls (tablet/iPad compatible)
- Offline-first with server sync (localStorage + Node.js/MongoDB backend)

## Success Metrics
- Kids voluntarily replay levels (engagement)
- Word retention improves across play sessions (learning)
- Parents see value without feeling it's "screen time" (perception)
- Adding a new language takes < 1 hour of non-coding effort
